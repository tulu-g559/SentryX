# SentryX 🛡️

An AI-powered "Mission Control" and autonomous observer for local microservices.

## Tech Stack
* **CLI:** Python
* **Backend:** Flask, MongoDB, Docker
* **Frontend:** React + Vite (Space-themed Neobrutalism)

## Quick Start
1. Ensure Docker is installed and running.
2. Run `make up` to spin up the SentryX Core backend and MongoDB.
3. Verify the core is online at `http://localhost:5000/health`.
